# The Human Thread

An original fictional demonstration essay about writing, AI and authorship, prepared for Ariane 0.2.0-alpha.1.

All people, institutions, dialogue and editorial observations are invented. The essay is not a scientific study or a factual history of artificial intelligence. It includes no private research or real interview material.

## Contents

- `Manuscript.md`: eight pages across four chapters, including a Markdown table.
- `Vault/`: ten notes covering fictional people, an institution, concepts and sources. Notes use YAML front matter and Obsidian-style links.

## Explore it in Ariane

1. Create a new project in a folder of your choice.
2. Import `Manuscript.md` into the open project. Use the import options to split the text into sections if desired.
3. Connect this example’s `Vault` folder as a read-only source vault, or copy its note folders into the new project’s own `Vault` folder.
4. Refresh the source index if needed, then open the beginning of the essay. Mara Vale, Jonas Reed and Northlight Writing Lab have matching notes.
5. Save a named version before revising a sentence to try the comparison view.

The source files are portable. The exact screenshot session also has local UI preferences and two labelled sample drafts; those database files are not distributed here.
