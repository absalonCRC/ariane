# Tool Evolution Map

## A framework for the essay

Correction proposes a local fix. Completion proposes a continuation. Collaboration proposes a possible direction for the work.

These categories describe a conceptual progression in the fictional manuscript. They are not a dated history, an exhaustive taxonomy or a comparison of specific products.

## Editorial question

Which decisions become easier to see, and which become easier to skip?
