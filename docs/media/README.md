# Ariane presentation media

Captured for the 0.2.0-alpha.1 presentation on 2 November 2026.

## Provenance

The eight JPEG screenshots show the actual native macOS application, using the fictional **The Human Thread** project. The window header is cropped to omit the macOS capture indicator; images are resized for the README. No interface controls, source results or product features were added to the screenshots.

The 46-second film combines those native screenshots, an actual recording of a source card opening, original typographic animation, and an original synthesized instrumental score. Product views are framed, cropped and moved as part of the edit. There is no generated or simulated product UI. The original score uses synthesized tones and noise, with no third-party recordings or samples.

All people, institutions, interviews and observations in the demo are fictional. The [portable Markdown material](../../examples/the-human-thread) is included in this repository. The complete native project, high-quality film master and editable production files are kept in the local Ariane Showcase folder.

`ariane-film.mp4` is the lightweight 720p/30 fps web copy. The release also includes the 1080p/60 fps master. `film-poster.jpg` links to it from the README. The film is understandable with sound off; all product claims are on screen. The README does not autoplay animation.
