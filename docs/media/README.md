# Ariane presentation media

Captured for the 0.2.0-alpha.1 presentation on 2 November 2026.

## Provenance

The JPEG images come from the actual native macOS application, using the fictional **The Human Thread** project. The sidebar is closed. The overview preserves the writing space; other images are close crops of the source card, editable table, source reader, search and export controls, or dark typography. The comparison pairs two exact excerpts from the native side-by-side view, stacked with editorial labels for readability. Window headers and macOS capture indicators are excluded. No interface controls, source results or product features were generated or added.

The revised 46-second film combines native screenshots, original typographic animation and an original synthesized instrumental score. Crops, changes of scale, camera movement and transitions guide attention from a sentence to its source, then to a revised passage. The source sequence composes captured excerpts; it is not a continuous screen recording. There is no generated or simulated product UI. The original score uses synthesized tones and noise, with no third-party recordings or samples.

All people, institutions, interviews and observations in the demo are fictional. The [portable Markdown material](../../examples/the-human-thread) is included in this repository. The complete native project, high-quality film master and editable production files are kept in the local Ariane Showcase folder.

`ariane-film.mp4` is the lightweight 720p/30 fps web copy. The release also includes the 1080p/60 fps master. `film-poster.jpg` is a separate poster; the README leads with the writing page. The film is understandable with sound off; all product claims are on screen. The README does not autoplay animation.
