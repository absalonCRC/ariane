# Signaler un problème de sécurité

Ariane est actuellement une alpha ; seule la dernière révision de cette alpha est ciblée par les corrections. Aucun délai de réponse n’est garanti.

Lors de l’ouverture du dépôt public, le mainteneur doit activer le signalement privé de vulnérabilités GitHub (onglet Security → Report a vulnerability). Tant que ce canal n’est pas disponible, demander au mainteneur un moyen de contact privé sans publier les détails exploitables.

Indiquer la version, la plateforme, les étapes de reproduction sur des données synthétiques et l’impact observé. Ne jamais joindre de manuscrit, de vault, d’enregistrement, de clé ou de base de données personnelle à une issue publique.

Le traitement du texte et des modèles est local. La construction et les installations facultatives téléchargent des dépendances externes ; cela reste une surface à vérifier. Les tests et l’audit npm ne constituent pas un audit de sécurité complet.
